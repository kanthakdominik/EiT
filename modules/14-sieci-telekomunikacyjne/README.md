# 14 — Sieci telekomunikacyjne

> **Status:** 🟡 szkielet — zakres i cele. Pełne notatki, zadania i zweryfikowane źródła w kolejnym etapie.

## Cel modułu

Rozumieć budowę i działanie sieci przenoszących dane i głos: od warstwy fizycznej po protokoły, z naciskiem na to, co dzieje się w sprzęcie.

## Wymagania wstępne

- [13 Telekomunikacja](../13-telekomunikacja/).

## Tematy

- [ ] Model OSI i stos TCP/IP — perspektywa inżyniera telekomunikacji
- [ ] Warstwa fizyczna: media przewodowe, światłowody, łącza radiowe
- [ ] Telekomunikacja światłowodowa: tłumienie, dyspersja, źródła i detektory optyczne, WDM
- [ ] Ethernet, przełączanie, VLAN
- [ ] Routing IP, adresacja, jakość usług (QoS)
- [ ] Komutacja łączy i pakietów, sieci szkieletowe
- [ ] Sieci dostępowe: xDSL, sieci kablowe, FTTH (PON)
- [ ] Sieci komórkowe: architektura 4G/5G, stacja bazowa, sieć rdzeniowa
- [ ] Sieci IoT i krótkiego zasięgu: BLE, Zigbee, LoRaWAN
- [ ] Teoria ruchu telekomunikacyjnego, wzór Erlanga, systemy kolejkowe
- [ ] Bezpieczeństwo transmisji — podstawy kryptografii w telekomunikacji

## Główne źródła

Zweryfikowane anglojęzyczne źródła dla tego modułu zostaną dodane w kolejnym etapie.

## Ćwiczenie modułowe

Zbuduj w symulatorze sieci (lub na kilku urządzeniach) sieć z dwiema podsieciami i routingiem; przechwyć ruch analizatorem pakietów i opisz enkapsulację ramki od warstwy aplikacji do fizycznej.

## Sprawdzian umiejętności

- Liczę budżet mocy łącza światłowodowego.
- Wyznaczam liczbę kanałów potrzebnych dla zadanego ruchu wzorem Erlanga B.
- Opisuję drogę pakietu przez sieć z routerem i przełącznikiem.
